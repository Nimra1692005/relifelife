How Mesh Network Works
1
Auto Detection
App automatically detects if internet is available. When online, uses WebSocket server for reliable messaging.
2
Offline → Mesh Activates
When internet is lost, app switches to Mesh Mode. Bluetooth and WiFi Direct connect nearby devices (up to 100m).
3
Communicate with Volunteers
Send messages, emergency alerts, and your GPS location to nearby volunteers and rescue teams — no internet needed.
4
Message Relay
Each device relays messages to further devices, extending range. A chain of phones can pass messages across km.
