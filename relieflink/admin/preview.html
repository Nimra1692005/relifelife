AI Flood-Risk Predictor

Logistic-regression ML model computing flood probability from live OpenWeatherMap rainfall forecasts

Model: Logistic Regression · 4 hydrological features · live data
--%
Flood probability — next 5 days
--
How this model works (fully transparent):
1️⃣ Pulls the live 5-day rainfall forecast (3-hour intervals) for the selected location from OpenWeatherMap
2️⃣ Extracts 4 hydrological features: cumulative rainfall, peak 24h rainfall, humidity, monsoon-season factor
3️⃣ Runs logistic regression — z = w₀ + w₁·rain₅d + w₂·rain₂₄h + w₃·humidity + w₄·monsoon → probability = 1/(1+e⁻ᶻ)
4️⃣ Weights calibrated on Pakistan flood thresholds (FFD/PMD historical patterns: 150mm+ cumulative = high alert)
